# Physix Org

Physix Org is an organization that houses multiple repositories spanning from games to applications.

This organization was established to centralize useful repositories together and separate my personal projects from organization type projects (games that might be published, apps people can use, etc).

## Contributing to Projects
At the moment there are very few projects people can contribute to. However you can still contribute to the projects if you so wish. Feel free to contact me (the owner) at llodgical018@gmail.com in order to participate to these projects.
